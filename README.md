# Studio Seven

An editorial, responsive website concept for a digital ventures company. It is built with React, Vite, TypeScript, Tailwind CSS v4, Framer Motion, and Lenis.

## Run locally

1. Install Node.js 20.19+ (or 22.12+).
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the local address Vite provides.

## Design decisions implemented

- Carbon-black architectural canvas with a subtle editorial grid.
- A restrained moss accent, used as the eastern light source.
- Hero-first storytelling: `IDEAS, BUILT.` and a CSS-built bamboo/light composition.
- Responsive single-line navigation with a mobile menu.
- 800ms signature reveals and measured hover interactions.
- Reusable section/layout components and accessible navigation landmarks.

Replace the CSS-built imagery in `src/components/sections` with final art-directed photography when those assets are ready.
